# TIMELINE — the real track and the campaign chronicle

**Part 1** is real history, the track the world runs on unless the characters change it.
Dates are ISO (`YYYY-MM-DD`) so that `python3 tools/dice.py date YYYY-MM-DD` finds them.
Mark each event **✔** when it has passed in play, or **✘ Dn** if a divergence changed it (and add
a "New history" line). Details and sources: `research/02_chile_timeline_2005_2026.md` and
`research/01_santiago_history.md`. After **2026-10-26** (the real present when this file was
written) history is the campaign's own.

**Part 2** is the campaign chronicle: what the characters did, in order.
